  FUNTIK — ИНСТРУКЦИЯ
  Локальная озвучка текста (Piper TTS)
================================================================================

БЫСТРЫЙ СТАРТ
-------------
1. Откройте generate.py — впишите текст в переменную text.
2. Откройте config.py — при необходимости измените настройки.
3. Запустите generate.py (Run в PyCharm или: python generate.py).
4. Готовый wav появится в папке output/ (каждый раз новое имя с версией).


================================================================================
  ЧТО ГДЕ НАХОДИТСЯ
================================================================================

generate.py     — текст для озвучки + запуск
config.py       — голос, скорость, интонация, паузы
output/         — готовые wav
voices/         — модели голосов
utils/          — код синтеза и скачивания
ИНСТРУКЦИЯ.txt  — этот файл


================================================================================
  ОСНОВНЫЕ НАСТРОЙКИ (config.py)
================================================================================

DEFAULT_VOICE
    Голос. Язык голоса = язык текста.
    Женский русский (единственный в Piper):
      ru_RU-irina-medium
    Мужские русские:
      ru_RU-dmitri-medium
      ru_RU-denis-medium
      ru_RU-ruslan-medium

SPEECH_SPEED
    Скорость речи. Меняется ЗАМЕТНО.
      1.0  — норма
      1.15 — быстрее
      0.90 — чуть медленнее
    Для приятного голоса обычно 0.90–1.05.
    Слишком низкая скорость (0.7 и ниже) часто звучит «как робот».

INTONATION
    Интонация / живость от 0.0 до 1.0. Меняется ЗАМЕТНО в разумных пределах.
      0.0  — ровнее
      0.55 — баланс (по умолчанию)
      1.0  — живее
    Внутри безопасно переводится в параметры Piper.
    Значения вроде noise_w=2 ЛОМАЛИ голос — теперь так нельзя.

VOLUME
    Громкость. 1.0 = норма, 1.2 = громче, 0.8 = тише.

NORMALIZE_AUDIO
    Нормализация. Обычно True.


ПАУЗЫ
-----
PAUSE_AFTER_SENTENCE
    Пауза после . ! ? … (секунды). Пример: 0.25–0.50

PAUSE_AFTER_PARAGRAPH
    Пауза между абзацами (пустая строка в тексте).

ВАЖНО ПРО «ЗАИКАНИЕ»
    Раньше текст резался по запятым и тире на куски
    («Сегодня —» отдельно) — из‑за этого голос заикался.
    Сейчас резка ТОЛЬКО по предложениям. Запятые и тире
    остаются внутри фразы — речь звучит естественно.


================================================================================
  ТОНКАЯ НАСТРОЙКА (обычно не нужна)
================================================================================

NOISE_SCALE / NOISE_W_SCALE
    Если None — берутся из INTONATION.
    Если задать число — перебивает INTONATION.
    Безопасный диапазон примерно 0.5–1.0.
    Значения выше ~1.2 часто дают артефакты.


================================================================================
  ИМЕНА ФАЙЛОВ
================================================================================

Каждый запуск создаёт новый файл, например:
  приветствую_..._spd0.95_n0.72_nw0.82_v1.wav
  приветствую_..._spd0.95_n0.72_nw0.82_v2.wav

В имени видно скорость (spd) и внутренние параметры (n, nw).
Старые файлы не затираются.


================================================================================
  РЕКОМЕНДУЕМЫЕ ПРЕСЕТЫ
================================================================================

Приятный женский рассказ:
  SPEECH_SPEED = 0.95
  INTONATION   = 0.55
  PAUSE_AFTER_SENTENCE = 0.35

Живее / сказочнее:
  SPEECH_SPEED = 0.90
  INTONATION   = 0.85
  PAUSE_AFTER_SENTENCE = 0.45

Быстрее:
  SPEECH_SPEED = 1.10
  INTONATION   = 0.45
  PAUSE_AFTER_SENTENCE = 0.25


================================================================================
  ОГРАНИЧЕНИЯ PIPER
================================================================================

• Настоящий «мультяшный Disney-голос» одной настройкой не получить —
  меняется ритм, паузы и вариативность, тембр = выбранная модель.
• Женский русский в Piper только irina.
• Самое сильное влияние на слух: SPEECH_SPEED, паузы, целые предложения.
