БЫСТРЫЙ СТАРТ
-------------
1. generate.py  — впишите текст в переменную text
2. config.py    — ENGINE = "cartoon" (полудетский мультяшный)
3. Run generate.py
4. Слушайте новый файл в output/


================================================================================
  ДВИЖКИ (config.py → ENGINE)
================================================================================

ENGINE = "cartoon"
    Полудетский / мультяшный голос (Microsoft Edge TTS).
    Нужен ИНТЕРНЕТ.
    Это то, что нужно для «мультяшного» звучания.

ENGINE = "piper"
    Локальный офлайн Piper.
    Взрослый тембр (irina и др.), настоящего мультика нет.


================================================================================
  CARTOON — ПОЛУДЕТСКИЙ МУЛЬТЯШНЫЙ (основные рычаги)
================================================================================

CARTOON_VOICE
    Диапазон:
      ru-RU-SvetlanaNeural  — женский (рекомендуется)
      ru-RU-DmitryNeural    — мужской

CARTOON_PITCH   ★ главный параметр «детскости»
    Формат: "+90Hz", "+110Hz", "-10Hz"
    Диапазон: мин. -50Hz … макс. +150Hz
    Рекомендуется для полудетского: +70Hz … +110Hz
    Выше = более детский / мультяшный

CARTOON_RATE
    Формат: "+8%", "-5%"
    Диапазон: мин. -50% … макс. +50%
    Рекомендуется: +0% … +15%

CARTOON_VOLUME
    Формат: "+0%", "+10%"
    Диапазон: мин. -50% … макс. +50%


Пресет «полудетский мультяшный» (уже стоит по умолчанию):
  ENGINE         = "cartoon"
  CARTOON_VOICE  = "ru-RU-SvetlanaNeural"
  CARTOON_PITCH  = "+90Hz"
  CARTOON_RATE   = "+8%"
  CARTOON_VOLUME = "+0%"

Ещё более детский:
  CARTOON_PITCH  = "+120Hz"
  CARTOON_RATE   = "+12%"


================================================================================
  PIPER (если ENGINE = "piper")
================================================================================

DEFAULT_VOICE   — ru_RU-irina-medium (жен.) и мужские dmitri/denis/ruslan
SPEECH_SPEED    — мин. 0.50 … макс. 1.50
INTONATION      — мин. 0.0 … макс. 1.0 (высокие значения → вздохи)
VOLUME          — мин. 0.10 … макс. 2.00
SPLIT_SENTENCES — False рекомендуется
