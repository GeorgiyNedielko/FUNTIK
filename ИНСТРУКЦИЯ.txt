4. Слушайте НОВЫЙ файл в output/


================================================================================
  ЧТО РЕАЛЬНО УМЕЕТ ГОЛОС (проверка API)
================================================================================

Движок cartoon = Microsoft Edge TTS.
Доступны ТОЛЬКО 4 параметра синтеза:
  1) voice   — какой голос
  2) pitch   — высота тона   (формат +NHz / -NHz)
  3) rate    — скорость      (формат +N% / -N%)
  4) volume  — громкость     (формат +N% / -N%)

НЕ поддерживается Edge TTS:
  • эмоции happy/sad/angry
  • отдельный «стиль» мультика
  • детский отдельный русский голос (есть только Svetlana и Dmitry)

Русские голоса Edge TTS:
  ru-RU-SvetlanaNeural  — женский (Friendly, Positive)
  ru-RU-DmitryNeural    — мужской (Friendly, Positive)

================================================================================
  ВЕСЁЛЫЙ МУЛЬТЯШНЫЙ ПРЕСЕТ (по умолчанию)
================================================================================

  ENGINE        = "cartoon"
  INTONATION    = 0.80     # детскость / высота
  CHEERFULNESS  = 0.90     # веселье / энергия ★
  CARTOON_VOICE = "ru-RU-SvetlanaNeural"
  CARTOON_PITCH = None     # авто из INTONATION+CHEERFULNESS
  CARTOON_RATE  = None
  CARTOON_VOLUME= None

Ещё веселее:
  INTONATION   = 0.90
  CHEERFULNESS = 1.00

Спокойнее:
  INTONATION   = 0.50
  CHEERFULNESS = 0.30


================================================================================
  ВСЕ НАСТРОЙКИ config.py
================================================================================

ENGINE
  Диапазон: "cartoon" | "piper"

INTONATION
  Диапазон: мин. 0.0 … макс. 1.0
  cartoon: высота/детскость
  piper: вариативность нейросети

CHEERFULNESS  ★ веселье
  Диапазон: мин. 0.0 … макс. 1.0
  Только cartoon: поднимает pitch + rate + volume
  При >= 0.55 точки в конце предложений заменяются на «!»

CARTOON_VOICE
  ru-RU-SvetlanaNeural | ru-RU-DmitryNeural

CARTOON_PITCH
  None или строка вида "+110Hz"
  Диапазон: мин. -50Hz … макс. +150Hz
  None = авто

CARTOON_RATE
  None или "+18%"
  Диапазон: мин. -50% … макс. +50%
  None = авто

CARTOON_VOLUME
  None или "+10%"
  Диапазон: мин. -50% … макс. +50%
  None = авто

--- Piper ---
DEFAULT_VOICE, SPEECH_SPEED (0.5–1.5), VOLUME (0.1–2.0),
NORMALIZE_AUDIO, SPLIT_SENTENCES, PAUSE_*, NOISE_*


================================================================================
  СОВЕТЫ ДЛЯ ВЕСЁЛОГО ЗВУЧАНИЯ
================================================================================

• CHEERFULNESS = 0.85–1.0
• В тексте используйте «!» и короткие фразы
• Не ставьте CARTOON_PITCH вручную, если крутите INTONATION/CHEERFULNESS
  (ручные значения перебивают авто)
