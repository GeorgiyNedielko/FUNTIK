ГДЕ ЧТО МЕНЯТЬ
--------------
1) Текст озвучки     → generate.py  (переменная text)
2) ВСЕ параметры     → config.py    (каждый с мин/макс в комментарии)
3) Запуск            → Run generate.py
4) Результат         → папка output/ (новый файл с версией)


================================================================================
  ПРАВИЛО
================================================================================

Все настройки голоса и постобработки правятся ТОЛЬКО в config.py.
В коде больше нет «скрытых» констант для эффектов.


================================================================================
  БЫСТРЫЕ РУЧКИ
================================================================================

ENGINE            cartoon | piper
INTONATION        0.0 … 1.0   детскость
CHEERFULNESS      0.0 … 1.0   веселье

Для точного ручного контроля cartoon:
  CARTOON_PITCH   = "+110Hz"   (вместо None)
  CARTOON_RATE    = "+18%"
  CARTOON_VOLUME  = "+10%"
None = авто из INTONATION + CHEERFULNESS.


================================================================================
  ПОСТОБРАБОТКА (всё вручную в config.py)
================================================================================

POSTPROCESS_ENABLED
POST_COMPRESSOR + THRESHOLD/RATIO/ATTACK/RELEASE
POST_EQ + HIGHSHELF/PRESENCE (+ Q)
POST_NORMALIZE + PEAK_DB
POST_LIMITER + THRESHOLD/RELEASE
POST_TRIM_SILENCE + THRESHOLD/MAX_SEC/FRAME_MS
POST_FADES + FADE_IN/OUT
POST_PITCH_SHIFT + SEMITONES

pip install -r requirements.txt
